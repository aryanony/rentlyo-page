Engineering Transparency

How can server costs genuinely be ₹0?

Google provides the Firebase Spark plan for free to developers worldwide. Because Rentlyo's database architecture is lean and strictly optimized:

  • 50,000 daily reads included for free (a 25-unit building uses < 2,000/day).
  • 20,000 daily writes included for free (normal rent payments use < 200/day).
  • 1 GB Firestore storage free forever (stores years of text rent transactions).
  • Zero domain costs: Android apps communicate directly via secure HTTPS APIs.
